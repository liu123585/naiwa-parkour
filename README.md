# 奶蛙跑酷 NAWA RUN

一款纯前端 HTML5 的「地铁跑酷」高仿小游戏，主角是网络迷因 **奶蛙**（AI 生成的奶龙变异体：黄桃罐头色的巨头身体、黝黑四肢、魔性大笑）。

零依赖、零外部素材：**所有角色建模、场景、特效都是代码矢量绘制，音效与背景音乐由 Web Audio 实时合成**，打开即玩，无需联网加载任何资源。

## 玩法

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 变道 | ← → / A D | 左右滑动屏幕，或左下角箭头按钮 |
| 跳跃 | ↑ / W | 上滑，或点击屏幕 |
| 滑铲 | ↓ / S | 下滑，或右下角按钮 |
| 悬浮板 | 空格 / Shift / B | 双击屏幕，或右上角粉色按钮 |
| 暂停 | P / Esc | 右上角暂停按钮 |

核心机制（对标地铁跑酷）：

- **三跑道无尽跑酷**，速度随距离持续提升
- **障碍类型**：栏杆/垃圾桶/交通锥（跳）、限高门架（滑铲）、停放列车（变道或跳上车顶）、迎面驶来的列车（有预警提示）
- **道具**：金币磁铁、喷射背包（飞越一切）、双倍金币、超级跑鞋（跳更高）、悬浮板（挡一次撞击）
- **跳上车顶**跑酷、**弹跳垫**起飞、**擦身而过**加分、**检票员与狗**开局追逐
- **昼夜与天气循环**：晴日 → 黄昏 → 霓虹夜轨 → 雨夜
- **复活机制**：每局可花金币复活一次
- **分数倍数**：随距离提升，最高 x5，双倍金币道具可再翻倍

## 本地运行

纯静态站点，任意静态服务器即可：

```bash
# 项目根目录
python -m http.server 8080
# 或
npx serve .
```

然后访问 http://localhost:8080 。直接双击 `index.html` 大多数浏览器也能跑，但建议用本地服务器。

## 自测

内置 headless 自测脚本（mock canvas / DOM / localStorage / AudioContext）：

```bash
node tools/selftest.js
```

覆盖：初始化、全部角色 × 全部动作姿态绘制、菜单/商店/任务/设置面板、商店购买、4 分钟随机输入对局、**智能 bot 生存测试（验证关卡永远有解）**、结算与复活、暂停恢复、画质切换、音频合成调用、存档清空。

## 目录结构

```
index.html          入口与全部界面骨架
css/style.css       界面样式（纯 CSS 绘制图标）

js/audio.js         Web Audio 音效合成 + 8-bit 循环 BGM
js/chars.js         10 个角色的矢量「建模」与跑步/跳跃/滑铲/飞行动画
js/draw.js          伪 3D 渲染引擎（透视投影、地面铁轨、接触网、火车箱体、粒子、天气）
js/ui.js            界面交互、商店、任务、成就、设置
js/game.js          主循环、物理、碰撞、道具、追逐、关卡段落生成
tools/selftest.js   headless 自测脚本
```

## 技术要点

- **伪 3D 投影**：`sx = cx + (x - camX) * f / z`、`sy = horizon + (camY - y) * f / z`，物体按 z 从远到近排序绘制，火车用「可见面」多边形拼出真实箱体透视。
- **角色建模**：归一化骨架空间（脚底 y=0、头顶 y≈1、y 轴向上），按跑步相位驱动四肢摆动，同一套绘制函数支持背视（游戏内）与正视（菜单/商店），因此商店缩略图和场上角色完全一致。
- **性能**：金币/道具用离屏预渲染精灵；DPR 上限分级（中画质 1.25）；运行时自适应降分辨率与降特效（帧率检测）。
- **音频**：全部由振荡器 + 噪声缓冲实时合成，奶蛙的「卡痰音大笑」用 6 段下行锯齿波模拟。
