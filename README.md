# 奶蛙跑酷 · NAWA RUN

一个纯前端（HTML5 + Canvas，无框架、无外部素材）的 3 跑道无尽跑酷网页游戏，玩法高仿《地铁跑酷》，
主角是 2026 年爆火的网络迷因「奶蛙」（奶龙的 AI 变异体：黄桃罐头色巨头、四肢黝黑、魔性大笑），
并加入东北雨姐、疯狂小杨哥等网红卡通戏仿角色供玩家解锁使用。

## 在线游玩

- GitHub Pages / EdgeOne Pages：部署后访问站点根目录即可
- 本地：直接双击 `index.html`，或用任意静态服务器（如 `npx serve`）

## 玩法

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 左右变道 | ← / → 或 A / D | 左右滑动、底部箭头按钮 |
| 跳跃 | ↑ / W | 上滑、点按屏幕、跳按钮 |
| 滑铲 | ↓ / S | 下滑、铲按钮 |
| 悬浮板 | 空格 / Shift / B | 双击屏幕、右上角悬浮板按钮 |
| 暂停 | P / Esc | 右上角暂停按钮 |

核心系统：

- **三条轨道**：栏杆（跳）、限高架（滑铲）、垃圾桶、雪糕筒、弹跳垫
- **车厢**：矮车厢（1.35m）可跳上车顶捡金币，高车厢（3.3m）必须变道，迎面列车会有警示提示
- **道具**：金币磁铁 / 喷射背包 / 双倍金币 / 超级跑鞋 / 悬浮板（可挡一次撞击）
- **追逐**：开局检票员与狗从身后追来，撞车后会被抓住
- **复活**：每局一次，消耗金币（技能可打折）
- **天气与昼夜**：晴日 / 黄昏 / 霓虹夜 / 雨夜，自动循环并平滑过渡
- **角色**：10 个可解锁角色，各自带被动技能；另有「雨姐的鹅」等整活角色
- **成长**：金币商店、5 项技能升级、每日任务（按日期种子生成）、15 个成就、最佳成绩记录

所有存档都在浏览器 `localStorage`（键名 `naiwaRun.save.v1`），没有后端。

## 目录结构

```
index.html          入口，含全部界面骨架与启动脚本
css/style.css       全部界面样式（HUD、菜单、商店、任务、结算）
js/config.js        常量、角色数据、技能/道具、任务池、成就、存档系统
js/audio.js         Web Audio 实时合成音效与 8-bit 循环 BGM（无音频文件）
js/chars.js         角色「建模」：矢量化骨架 + 跑步/跳跃/滑铲/翻滚/飞行动画
js/draw.js          伪 3D 渲染引擎：透视投影、天地景、铁轨、接触网、车厢、道具、粒子
js/ui.js            界面交互、商店、任务、成就、设置
js/game.js          游戏主循环、物理、碰撞、道具、追逐、关卡生成器
tools/selftest.js   headless 自测（mock canvas/DOM 跑完整对局，含智能 bot 可通过性验证）
tools/shot.ps1      用本机 Edge 无头模式批量截图（开发自用）
```

## 开发自测

```bash
node tools/selftest.js      # 逻辑自测：12 个角色绘制、面板、商店、4 分钟随机对局、5 分钟 bot 生存、音频、存档
```

自测里的 bot 会读取赛道信息做避让，用来验证「关卡一定有解」（不会出现三条道全封死）。

## 调试参数

在网址后追加查询参数（仅用于开发和截图，不影响正常游玩）：

- `?dev=run` 直接开跑；`&god=1` 无敌；`&warp=900` 快进 900 帧
- `&theme=night|dusk|rain|day` 指定天气
- `?chars=1` 打开角色商店面板

## 说明

- 角色形象均为卡通戏仿演绎，仅供娱乐，与原人物/作品无关联。
- 玩法灵感来自《地铁跑酷（Subway Surfers）》；「奶蛙」为网络迷因形象。
- 音效与音乐全部由 Web Audio 实时合成，不包含任何第三方素材文件。
